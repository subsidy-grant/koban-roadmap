# リスキリング助成金（定額制サービスによる訓練）一式

人材開発支援助成金／事業展開等リスキリング支援コース【定額制サービスによる訓練】を、
複数企業の担当者1人が期限を落とさずに回すための道具一式。

| ファイル | 中身 |
|---|---|
| `../reskilling.html` | 期限管理画面。契約開始日から計画届・支給申請の期限と逆算マイルストーンを自動計算。CSV/ICS/印刷/バックアップ対応 |
| `dist/リスキリング助成金_複数社管理チェックシート.xlsx` | Excel版。8シート（使い方／期限一覧／逆算スケジュール／チェックリスト／やってはいけないこと／事前スクリーニング／税務の注意／要確認リスト） |
| `dist/リスキリング助成金_社内配布用様式集.docx` | Word版。様式1〜6（社長通達・業務命令書・書類依頼・受講記録・事前スクリーニング・チェックシート）＋付録 |
| `SOURCE_DIGEST.md` | 紙資料から抽出した記述一覧（A〜J、44項目）。監修の共通入力 |
| `KANSHU_REPORT.md` | 社労士・税理士・診断士の3観点による監修レポート（統合・重大度順） |

## 期限の計算規則（画面・Excelとも同一）

- 計画届＝契約開始日の1か月前の同じ日（応当日が無い月は末日に丸める）
- 訓練終了日＝契約終了日。未入力なら契約開始日から1年間
- 支給申請＝訓練終了日の2か月後の同じ日（＝翌日から起算して2か月以内）
- 契約が1年を超える場合は1年ごとに区切り、区切りごとに申請期限を出す

紙資料に載っている全例（4/1→3/1、6/1→5/1、10/1→9/1、3/31終了→5/31）と一致することを、
実ブラウザ（Chromium）とExcel式の等価実装の両方で確認済み。
